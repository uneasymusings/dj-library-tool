# Public review-page preview

This folder is generated by `scripts/showcase/build_preview.py` from the production frontend and five isolated CLI/API captures using original generated audio. It contains no audio, user catalog, authentication token or real workstation paths.

`app.js` is the production frontend with only its automatic startup deferred. `demo.js` supplies the explicit read-only data transport, then starts that frontend. Every write request is rejected with instructions to use the local app. The site never searches providers, downloads music or automates a DJ app. Saved BPM/key values are illustrative.

Run `python scripts/showcase/build_preview.py --check` to confirm that the public UI still matches production. `catalog.json` is example data; `manifest.json` records content hashes. GitHub Pages serves this directory under `/dj-library-tool/preview/`.

For UI-only changes, `python scripts/showcase/build_preview.py --refresh-ui` updates the copied frontend while retaining the fixture catalog. Static asset URLs carry content hashes so a new deployment cannot mix cached UI revisions.
